파얼끄투 개인정보 처리방침 (Privacy Policy)

"파얼끄투"는 로블록스 로그인 연동 시 사용자의 개인정보를 소중히 다루며, 관련 법령을 준수합니다.

1. 수집하는 개인정보 항목

로블록스 로그인 시 유저 고유 식별자 번호(sub), 유저네임(Username), 표시 이름(Display Name)을 수집합니다. 실제 개인을 식별할 수 있는 이름, 이메일, 비밀번호 등은 절대 수집하지 않습니다.

수집된 정보는 파얼끄투 프리서버의 회원가입, 중복 가입 확인, 게임 내 프로필(닉네임 및 아바타 헤드샷) 표시 목적으로만 제한적으로 사용됩니다.

3. 개인정보의 보유 및 파기

사용자가 회원 탈퇴를 요청하거나 서비스를 더 이상 이용하지 않을 경우, 수집된 데이터는 데이터베이스에서 즉시 안전하게 파기됩니다.
